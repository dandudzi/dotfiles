# CV comparison methodology

## Extract evidence

Read the whole CV and the complete captured posting. Catalogue the posting's hard requirements, preferred requirements, responsibilities, technologies, seniority, domain, and implicit expectations. Catalogue the CV's skills, technology claims, scope and ownership signals, quantified outcomes, domain experience, and seniority signals.

Use the posting as the source for the role. Use the CV as the source for the candidate. Do not infer unlisted experience.

## Score the match

Score each hard requirement and each preferred requirement as:

- **1** — clearly demonstrated by the CV.
- **0.5** — partial or implied evidence.
- **0** — no CV evidence.

For each group, calculate `(points / number of requirements) * 10` and round to one decimal. If the posting has no requirements in a group, write `Not specified in posting` rather than divide by zero.

Score seniority alignment:

- **10** / 🟢 — CV is within one seniority notch of the target.
- **5** / 🟡 — credible stretch or overqualification risk.
- **0** / 🔴 — clear mismatch.

Calculate technology overlap as `(distinct posting technologies found or closely equivalent in CV / distinct posting technologies) * 100`. Write `Not specified in posting` when none are named.

Score domain fit:

- **10** / 🟢 — same or closely adjacent domain.
- **5** / 🟡 — transferable domain.
- **0** / 🔴 — unrelated domain.

Calculate the overall fit as the numeric weighted average: required qualifications **40%**, preferred qualifications **20%**, seniority **20%**, technology overlap converted to a ten-point score **20%**. If a component is not specified by the posting, reweight the available components proportionally and disclose that adjustment.

## Analyse gaps and tailoring

Call a gap **hard** only when the CV does not demonstrate it; state its precise scope, severity, and whether it is bridgeable. Call a gap **presentation** when the CV likely contains the evidence but fails to surface it; identify the exact role, project, or bullet and a truthful change.

Select 3–5 strengths with concrete CV evidence that maps to the role's responsibilities. Rewrite only 3–6 bullets that undersell relevant work, use different terminology than the posting, or bury the impact. Quote the original and use a truthful action–scope–outcome replacement. Give exact keyword-placement instructions, structural changes only when justified by the posting, and a 2–4 sentence summary/headline rewrite.

Flag only genuine concerns in the posting, such as unrealistic scope, seniority or stack mismatch, culture signals, overqualification risk, vague definition, or visible compensation constraints. Derive 4–6 likely interview questions only from meaningful gaps. Do not add preparation advice to that list.

## Quality checks

Fill every template section. Use exact CV and posting wording where relevant. Use a single numeric score, never a range. Leave no placeholders. Write `*None identified.*` when a section has no evidence-backed content.
