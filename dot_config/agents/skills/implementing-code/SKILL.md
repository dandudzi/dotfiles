While coding find if repository use Domain Driven Design. Hence read `CONTEXT.md` to understand ubiquitous language. While coding use DDD patterns like:

- **Entity**
- **Value Object**
- **Aggregate**
- **Aggregate Root**
- **Repository**
- **Factory**
- **Domain Service**
- **Application Service / Use Case**
- **Domain Event**
- **Command**
- **Command Handler**
- **Bounded Context**
- **Anti-Corruption Layer (ACL)**
- **Domain Model**
- **Specification**
- **Policy**
- **Module / Domain Package** — groups model code by domain capability, not technical layer.
- **CQRS**
